# Security reports

For screenshot disclosure, capability leaks or unauthorized local-service access, email **[z5866318@gmail.com](mailto:z5866318@gmail.com)** privately. Start with the release version, macOS version, issue category and a safe reproduction summary. Do not include real capability URLs, settings access addresses, credentials, full desktop screenshots or complete system logs. Coordinate any sensitive evidence privately before sending it.

Ordinary bugs can use [GitHub Issues](https://github.com/amingclawdev/seethis/issues/new/choose). The Inspector's Feedback… button opens an email draft; SeeThis does not send it automatically.

This project currently maintains the `v0.1.0-beta.1` prerelease for Apple Silicon/macOS 14.2+. There is no guaranteed response time or completed security-audit claim. Updates are manual; check the release page for fixes.

Reference URLs authorize local reads. Captures contain the entire selected display. Deleting a local reference cannot retract attachments already shared or backups. Developer ID signing and Apple notarization verify distribution identity and Apple's acceptance of the submitted payload; they do not replace reviewing the screenshot or choosing trusted recipients. See [PRIVACY](PRIVACY.md) and [release verification limits](docs/RELEASE.md).
